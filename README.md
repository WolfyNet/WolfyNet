# Installation

## Chrome / Chromium

1. Téléchargez ou clonez ce repository.
2. Ouvrez `chrome://extensions`.
3. Activez le **Mode développeur**.
4. Cliquez sur **Charger l’extension non empaquetée** (*Load unpacked*).
5. Sélectionnez le dossier contenant `manifest.json`.

📖 [Documentation officielle Chrome — Load unpacked](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world)

## Firefox

1. Téléchargez ou clonez ce repository.
2. Ouvrez `about:debugging`.
3. Cliquez sur **Ce Firefox** (*This Firefox*).
4. Cliquez sur **Charger un module complémentaire temporaire** (*Load Temporary Add-on*).
5. Sélectionnez le fichier `manifest.json` de l’extension.

⚠️ L’installation via `about:debugging` est temporaire et l’extension devra être rechargée après le redémarrage de Firefox.

📖 [Documentation officielle Mozilla — Installation temporaire](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/)

---

## Autres navigateurs Chromium

Les navigateurs basés sur Chromium proposent généralement une procédure similaire à Chrome :

1. Ouvrez la page de gestion des extensions.
2. Activez le **Mode développeur**.
3. Utilisez **Load unpacked / Charger l’extension non empaquetée**.
4. Sélectionnez le dossier contenant `manifest.json`.

La procédure exacte peut varier selon le navigateur. Consultez sa documentation officielle pour plus d’informations.
